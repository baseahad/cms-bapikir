# Copy-Paste dari Mouse: Gak Perlu Keyboard Buat Ctrl+C Ctrl+V

Kalo lo sering:

- Copy teks bolak-balik pas nulis
- Paste berkali-kali pas coding
- Pindah data dari satu app ke app lain

...lo pasti udah hafal gerakan *Ctrl+C, Ctrl+V* ribuan kali sehari.

Tapi ada cara yang lebih cepat: **assign copy & paste ke tombol samping mouse.** Tinggal klik, tanpa mindahin tangan dari mouse ke keyboard.

Dua cara, tergantung mouse lo.

---

## Cara 1: Pake Logi Options+ (Mouse Logitech)

Buat pengguna mouse Logitech kayak M185, M220, M330, MX Anywhere, atau MX Master:

1. Buka **Logi Options+**
2. Klik gambar mouse lo
3. Pilih tombol yang mau diubah (biasanya tombol samping kiri/kanan)
4. Pilih **Key Shortcut**
5. Untuk copy: tekan **Ctrl + C**
6. Untuk paste: pilih tombol samping satunya → **Ctrl + V**
7. Simpan

**Kendala yang sering terjadi:** Logi Options+ kadang gak mau kebuka atau UI-nya error. Kalau begitu, langsung ke Cara 2.

---

## Cara 2: Pake X-Mouse Button Control (Semua Mouse)

X-Mouse Button Control adalah software gratisan yang jauh lebih ringan dari Logi Options+. Ukurannya cuma **2 MB**, gak perlu login, gak perlu service latar.

**Download:** [https://www.highrez.co.uk/downloads/xmousebuttoncontrol.htm](https://www.highrez.co.uk/downloads/xmousebuttoncontrol.htm)

**Setting copy-paste:**
1. Install & buka X-Mouse
2. Di tab **Button Mapping**, pilih tombol samping (Button 4 atau Button 5)
3. Pilih **Simulated Keys**
4. Di kolom: klik **Click** → pilih **Ctrl+C** buat copy
5. Ulangi buat tombol satunya → **Ctrl+V** buat paste
6. Klik **Apply**

Selesai. Tombol samping mouse lo sekarang jadi copy-paste.

**Kelebihan X-Mouse:**
- Ringan (2 MB, gak kayak Logi Options+ yang 200 MB + service-service)
- Kerja offline
- Profile per aplikasi (misal: di Excel beda setting, di browser beda)
- Gak perlu restart

## Ide Mapping Lain Buat Tombol Samping

Tombol samping mouse itu sayang kalo cuma buat back-forward browser. Coba mapping ini:

| Tombol | Fungsi | Cocok buat |
|--------|--------|------------|
| Samping 1 | **Ctrl+C** (Copy) | Kerja dokumen |
| Samping 2 | **Ctrl+V** (Paste) | Kerja dokumen |
| Scroll kiri | **Ctrl+Z** (Undo) | Nulis, desain |
| Scroll kanan | **Ctrl+Y** (Redo) | Nulis, desain |
| Samping 1 + klik | **Win+Tab** | Ganti window |
| Samping 2 + klik | **Alt+F4** | Tutup app |

## Tambahan: Middle Click Buat Close Tab

Ini satu lagi yang jarang diketahui: **klik tengah (scroll) di tab browser = nutup tab.** Gak perlu cari tombol X kecil.

Biasanya udah default di semua browser:
- Klik tengah di tab → **nutup tab**
- Klik tengah di link → **buka di tab baru**
- Klik tengah di bookmark bar → **buka di tab baru**

Kombinasikan dengan copy-paste di tombol samping, kerja jadi jauh lebih cepat tanpa mindahin tangan.
