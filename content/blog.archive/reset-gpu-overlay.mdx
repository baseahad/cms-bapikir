# Cara Reset GPU Overlay Tanpa Restart Laptop

Pernah nemu layar tiba-tiba ada **layer putih, bayangan, atau artefak grafis** yang:

- Gak bisa diclick
- Gak bisa digeser
- Gak ilang setelah tutup semua aplikasi
- Tapi ilang kalau Win+D (show desktop) terus muncul lagi?

Itu bukan hantu di laptop. Itu **GPU overlay**, lapisan grafis yang dirender langsung oleh kartu grafis, bukan oleh Windows Explorer.

Overlay biasanya dipakai sama aplikasi screen capture, OBS, game overlay, atau tool otomatisasi browser. Masalahnya: kalau aplikasi pembuatnya crash atau ditutup paksa, overlay-nya kadang **nyangkut** di GPU dan gak ilang meskipun aplikasi induknya udah mati.

Berikut 3 cara ngatasinnya, dari yang paling simpel ke paling radikal.

---

## Cara 1: Monitor Power Cycle

Ini paling simpel dan seringkali cukup. Prinsipnya: matiin display, hidupin lagi. Ini nge-reset surface rendering GPU tanpa harus restart Windows.

**Caranya:**
- Tekan **Win + Ctrl + Shift + B** - ini shortcut reset graphics driver bawaan Windows
- Atau lewat command: matikan monitor lewat power setting, tunggu 5 detik, hidupkan lagi

**Efektif untuk:** Overlay DirectX yang nyangkut ringan.

---

## Cara 2: Ganti Resolusi Display

Kalau cara 1 gak mempan, paksa GPU buat re-initialize seluruh pipeline rendering dengan ganti resolusi.

**Caranya:**
1. Klik kanan desktop → **Display Settings**
2. Di **Display resolution**, pilih resolusi yang lebih rendah (misal 1360x768 → 1280x720)
3. Klik **Keep changes**
4. Tunggu 3 detik
5. Balikin ke resolusi semula

Proses ini memaksa GPU untuk:
- Drop semua surface yang ada
- Re-create framebuffer dengan ukuran baru
- Nge-load ulang semua texture & overlay

**Efektif untuk:** Overlay Intel HD Graphics / DirectX yang bandel.

---

## Cara 3: Restart Desktop Window Manager (DWM)

DWM adalah komposer grafis Windows. Dia yang ngatur semua window rendering, efek transparansi, dan tampilan visual. Merestart DWM sama kayak "refresh desktop" versi dalem.

⚠️ **Catatan:** Cara ini bakal bikin layar kedip sebentar. Save kerjaan lo dulu.

**Caranya:**
Buka Task Manager → tab Details → cari **dwm.exe** → klik kanan → **End task**.

Atau lewat Command Prompt (admin):
```
net stop uxsms /y
net start uxsms
```

Setelah itu, desktop lo akan refresh total. Semua overlay yang nyangkut - termasuk dari aplikasi yang udah mati - bakal ilang.

**Efektif untuk:** Overlay membandel dari aplikasi third-party.

---

## Kapan Perlu Restart?

Kalau 3 cara di atas udah dicoba semua dan masih bandel, kemungkinan ada **driver GPU yang corrupted** atau **aplikasi dengan hardware access level** yang masih nahan resource.

Restart laptop solusi terakhir. Tapi jarang banget diperlukan, 95% kasus cukup pake Cara 1 atau 2.
